# Supplementary Data: numerical figure-source workbooks

This folder contains the 21 previously checked figure-specific Excel workbooks (4 main-manuscript figures and 17 supplementary figures), plus the source-data index and figure-number crosswalk. Their numerical cells have not been altered as part of this repository curation. No new scientific results were calculated for these workbooks.

These files may be submitted to the journal under the Supplementary Data file type, consistent with the editor's instructions, and may be linked through the repository once its actual public URL is available. All workbooks should be checked against the **final** figure-numbering order before submission. External underlying raw data are not included in the workbooks as full third-party database redistributions.
